# EDA Playground

This repository contains Exploratory Data Analysis (EDA) projects using Python, Pandas, and Seaborn on real-world datasets.

## Datasets Used
- Titanic Dataset
- Tips Dataset
- Iris Dataset
- Flights Dataset

## Tools & Libraries
- Python
- Pandas
- Seaborn
- Matplotlib

## Key Analysis Performed
- Univariate Analysis
- Bivariate Analysis
- Data Visualization
- Correlation Insights

## Sample Insights
- Relationship between total bill and tips
- Survival trends based on age and gender
- Distribution patterns in datasets

## Project Goal
To practice and demonstrate data analysis and visualization skills.
